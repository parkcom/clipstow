# Support

Use [GitHub Issues](https://github.com/parkcom/clipstow/issues) for reproducible bugs, feature proposals, and build questions.

Before posting:

- Check the README and existing issues.
- Include your macOS and Xcode versions.
- Do not post private notes, clipboard contents, credentials, or signing material.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not the public issue tracker.
