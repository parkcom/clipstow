ClipStow 0.1.0-beta.3 adds a local Folder workspace alongside Notes and Scratchpad, and keeps Markdown Preview line breaks aligned with the editor.

## Install

1. Download `ClipStow-0.1.0-beta.3.dmg` below.
2. Open it and drag ClipStow into Applications.
3. Launch ClipStow from Applications. It appears in the menu bar.

The app requires macOS 13 Ventura or later. The universal build supports Apple Silicon and Intel Macs. This download is signed with Developer ID and notarized by Apple.

## What's new

- Added a Folder section with user-selected folder access that can be restored across launches.
- Added automatic file-list refresh, sorting by name, modified date, or size, and file metadata.
- Added inline and full Quick Look previews plus dragging files into other apps.
- Added Command-click multi-selection and `Command+A` Select All.
- Added Finder-style actions for opening, Quick Look, revealing, renaming, duplicating, copying, getting info, and confirmed moves to the macOS Trash.
- Preserved single line breaks from Markdown source when rendering Preview.

## Privacy

Notes stay in the app sandbox on your Mac. Scratchpad content is not written to disk. Folder access is limited to the folder you select, and write access is used only for explicit file actions. ClipStow has no account, analytics, telemetry, cloud sync, or application-level network requests.

## Beta limitations

- Automatic updates are not available; install newer versions from GitHub Releases.
- Search, attachments stored inside notes, tags, sync, sharing, version history, and deletion recovery are not included.
- Clipboard changes overwritten within the 250 ms polling interval cannot be recovered.
- Unsaved Scratchpad content disappears when ClipStow quits.

Please report reproducible problems through [GitHub Issues](https://github.com/parkcom/clipstow/issues) after removing private note, clipboard, and file information from screenshots and logs.
