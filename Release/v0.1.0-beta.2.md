ClipStow 0.1.0-beta.2 improves responsiveness when editing notes, switching Markdown preview modes, and working with a busy Scratchpad.

## Install

1. Download `ClipStow-0.1.0-beta.2.dmg` below.
2. Open it and drag ClipStow into Applications.
3. Launch ClipStow from Applications. It appears in the menu bar.

The app requires macOS 13 Ventura or later. The universal build supports Apple Silicon and Intel Macs. This download is signed with Developer ID and notarized by Apple.

## Improvements

- Reduced note editor latency with isolated drafts and debounced persistence.
- Cached Markdown preview parsing and reduced unnecessary Notes interface updates.
- Remembered the Edit or Preview selection across note changes, popover reopen, and app relaunch.
- Isolated Scratchpad changes from the Notes interface.
- Stopped clipboard polling whenever Copy Capture is off.
- Added expandable previews for long Scratchpad entries while preserving their complete original text.
- Reduced repeated formatting, allocation, and row rendering work in Scratchpad.

## Privacy

Notes stay in the app sandbox on your Mac. Scratchpad content is not written to disk. ClipStow has no account, analytics, telemetry, or cloud sync.

## Beta limitations

- Automatic updates are not available; install newer versions from GitHub Releases.
- Search, attachments, tags, sync, sharing, version history, and deletion recovery are not included.
- Clipboard changes overwritten within the 250 ms polling interval cannot be recovered.
- Unsaved Scratchpad content disappears when ClipStow quits.

Please report reproducible problems through [GitHub Issues](https://github.com/parkcom/clipstow/issues) after removing private note and clipboard content from screenshots and logs.
