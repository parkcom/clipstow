# Security Policy

## Supported versions

ClipStow is currently a beta-stage source release. Security fixes are applied to the latest revision on the default branch.

## Reporting a vulnerability

Do not include sensitive clipboard contents, personal notes, credentials, or exploit details in a public issue.

Use GitHub's **Private vulnerability reporting** feature on this repository when available. If it is unavailable, open a public issue containing only a request for a private contact channel and no vulnerability details.

Please include the affected revision, macOS version, impact, and minimal reproduction information. Reports will be acknowledged as soon as reasonably possible; no fixed response-time SLA is currently offered.
